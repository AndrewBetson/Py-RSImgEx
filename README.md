Python utility that extracts or lists files from (most) sixth generation Rockstar IMG archives.

# Supported Formats
- Version 1 (III/VC/SA/Bully)
- Version 1X (III/VC XBOX)
- Version 2 (SA)

# Usage
If running from source, install dependencies using `pip install -r requirements.txt`

Execute `python main.py -h` for full usage info.
